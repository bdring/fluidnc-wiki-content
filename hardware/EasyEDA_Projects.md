# EasyEDA

![easyeda.png](/easyeda.png =x500)

EasyEDA is a free PCB design tool. The basic version is web based so you do not need to install the program and you can access it from any computer.

The program is tightly integrated with JLCPCB and LCSC, but you can order from any supplier. If you use JLC parts, you never have to draw a symbol or footprint and you can easily check costs and stock levels as you are designing. The other advantage is the "one-click" ordering system. You can order fully assembled PCBs without any PCB or electronics knowledge.

Many controller designs were ported to EasyEDA to take advantage of the "one-click" ordering feature and the ability to clone designs and collaborate with others. [Over a dozen designs are available here](https://oshwlab.com/bdring?tab=project&page=1).

All of the designs are done in the basic (free) level. It is recommended to stay wit that level if you want to share your design or collaborate (get help).

## Making New Designs

### Cloning

You can clone a design if you want to make simple changes to an existing design.

### Copy Paste

If you want a hybrid of features from multiple designs, it can be easier to cut and paste sections from various designs into a new project.

## Share Alike and Donate

It was a lot of work to convert the designs. The net result is a loss in revenue from the Tindie store. If you are buying from JLCPCB rather than Tindie, please consider [donation to the FluidNC project](/home/#donations).

If you clone the design and modify the design you should share your version and credit the original designer.
