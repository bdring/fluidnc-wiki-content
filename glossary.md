# FluidNC Term Glossary

## DRO

DRO means Digital Read Out. For CNC is genrally means a digital display of the axis position. If we ask "are the DROs changing" it means, is the digital display of the axis values changing. 

![ugs_dros.png](/support/ugs_dros.png)

## Feedrate or Feed Rate

Feedrate refers to the speed of the machine in the direction of travel when in a feedrate controled mode (G1,G2,or G3).

## FNC

This is shorthand for FluidNC

## FT

This is shorthand for FluidTerm

## Grbl_ESP32 or GE

Grbl_ESP32 is the original version of FluidNC. When we made some major changes that started moving us past Grbl we changed the name. GE is a shortened name for that. 

## Mode

This a gcode term. It refers to the [modal states](http://wiki.fluidnc.com/en/features/supported_gcodes#modal-groups) of the gcode

## POG

If you see POG in a Discord post it refers to Plain Ole Grbl. This is the Gble and the gnea/grbl Github repo

## State

The term state with FluidNC generally means (Idle, Run, Hold, Alarm, Door, etc)
